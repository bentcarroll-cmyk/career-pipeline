# Backlog actions

Supported actions:

- summarize new Strong Match and Worth Considering issues;
- compare exact selected tickets using responsibilities, evidence-backed fit, gaps, compensation, location, recency, and deadlines;
- surface approaching deadlines and roles needing confirmation;
- set Not pursuing or another user-directed lifecycle label, then read it back;
- accept one or more exact ticket IDs for immediate packet preparation.

Do not create issues for roles that were not assessed by discovery. Do not treat label changes as background events. Packet preparation requires a current explicit request such as “Prepare an application packet for JOB-123.” For multiple tickets, preserve the user's order and role-specific instructions, then start the Prepare application skill without scheduling or deferring the work.
