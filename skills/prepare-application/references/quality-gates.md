# Packet quality gates

All gates must pass and produce a receipt under `working/`.

1. **Factual:** every employer-facing claim maps to an approved profile evidence ID or a verified posting fact; no unsupported additions.
2. **Chronology:** employers, roles, dates, transitions, and ordering agree with the latest user-approved chronology.
3. **Tailoring:** the highest-value supported evidence addresses the employer's central outcomes and does not merely repeat keywords.
4. **ATS structure:** conventional headings, selectable text, simple reading order, no essential information in images, headers, or footers.
5. **Page space:** no clipped, overflowing, orphaned, or wastefully sparse sections.
6. **PDF text:** extracted text is complete, ordered, and materially matches the approved source draft.
7. **Page count:** resume is exactly two pages; enabled cover letter is exactly one.
8. **Visual:** render every page and inspect typography, spacing, alignment, artifacts, and page balance.

Use the Codex document capability for authoring and the PDF capability for page count, extraction, rendering, and visual inspection. If either capability is unavailable, stop with an actionable explanation rather than marking a check complete.

Save drafts, extracted text, page renders, source snapshots, and the structured quality receipt in `working/`. Final employer-facing PDFs are the only PDFs directly in the version folder.
