# Evidence-led tailoring

Derive the central outcomes the employer is hiring for from verified responsibilities, not title alone. Rank approved accomplishments by:

1. relevance to the central outcomes;
2. measured impact;
3. clarity of the user's own contribution;
4. scope and complexity;
5. distinctiveness;
6. recency;
7. factual support; and
8. rendered page space.

Never invent a metric, responsibility, employer fact, technology, credential, date, or outcome. Preserve uncertainty and actionable gaps. A later explicit user correction overrides older resume text or extraction.

The resume must be clean, text-focused, ATS-friendly, and exactly two pages by default. The cover letter must be role-specific, evidence-led, and exactly one page when enabled. Apply Workday or another ATS-specific structural rule only after verifying that system is the actual application destination.
