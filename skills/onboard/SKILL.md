# Onboard

Guide the user through a resumable, local-first setup. Explain data handling accurately, require a working Linear destination, treat every other connector as an independent choice, preserve the source resume unchanged, and do not activate discovery until the user explicitly approves the profile and search criteria.

Create only discovery and eligible lifecycle automations after explicit approval. Never create an automation for application packets.
