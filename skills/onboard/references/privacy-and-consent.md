# Privacy and consent

Explain these points before requesting a workspace:

- Career Pipeline has no hosted service, shared database, telemetry, analytics, developer-controlled credentials, remote logging, or hidden network destination.
- The plugin contains reusable instructions, templates, schemas, deterministic helpers, and synthetic examples only.
- The user's private files, canonical opportunity backlog, lifecycle history, and application packets remain under a local root they approve.
- Connected services process requests under their own terms. The plugin author receives no automatic copy of local files, connector content, run records, exports, or feedback.
- Connector exports are optional actions and never replace local canonical records.
- Beta feedback is voluntary and manually shared.

Ask for approval before creating the root. If the user does not approve one, stop setup without creating files. Never describe third-party connector processing as entirely local.
