# Privacy and consent

Explain these points before requesting a workspace:

- Career Pipeline has no hosted service, shared database, telemetry, analytics, developer-controlled credentials, remote logging, or hidden network destination.
- The plugin contains reusable instructions, templates, schemas, deterministic helpers, and synthetic examples only.
- The user's private files remain under a local root they approve. The durable opportunity backlog and delivered attachments live in their own Linear workspace.
- Connected services process requests under their own terms. The plugin author does not receive an automatic copy of local files, connector content, run records, or feedback.
- Beta feedback is voluntary and manually shared.

Ask for approval before creating the local root. If the user does not approve one, stop setup without creating files. Never describe third-party connector processing as entirely local.
