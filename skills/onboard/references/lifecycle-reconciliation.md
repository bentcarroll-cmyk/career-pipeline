# Lifecycle reconciliation

This optional weekday workflow is available only when Gmail or Google Calendar is connected with the required read capability and the user opts in.

Read only job-related evidence. An automatic Linear status update requires one exact configured ticket and an unambiguous application confirmation, rejection, interview invitation, or offer. Match employer plus requisition identity when possible; otherwise require exact employer and role title. Read the Linear change back before recording success.

Route contradictory, employer-generic, multi-role, or otherwise ambiguous evidence to user review. Ignore unchanged evidence already represented by a receipt.

Persist only source kind, an opaque source-receipt hash, timestamp, event class, matched ticket, decision, and verified resulting status. Do not retain complete message or calendar bodies.

Never send or reply to email, accept an invitation, create an event, or contact another person. Calendar event creation remains a separate explicit user request outside reconciliation.
