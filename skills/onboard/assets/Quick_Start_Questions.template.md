# Quick-start questions

## Target work

- What work do you want to do next?
- Which role families or scope should the first discovery run include?

Record at least one user-provided target-work statement.

## Hard constraints

- Which compensation, location, workplace, authorization, travel, timing, or role conditions should exclude a job?
- Are there no hard exclusions yet?

Record the user's exact list, including an explicit empty list when they confirm there are no hard exclusions. Each hard exclusion still needs its own confirmation in the structured search criteria.
